Pembuat Token TimeBalance

Khusus admin. Buka file ini langsung di komputer (jangan diunggah ke website atau GitHub).

1. Kunci (cukup sekali di awal)

Kunci terdiri dari kunci rahasia (untuk membuat token, hanya Anda yang memegang) dan kunci publik (ditempel di www/app.js supaya aplikasi bisa memeriksa token).

⚠️ Simpan kunci rahasia di tempat aman (file di komputer + cadangan di Drive pribadi). Jika hilang, Anda tidak bisa membuat token lagi. Jika bocor, orang lain bisa membuat token Premium palsu. Jangan kirim ke siapa pun dan jangan unggah ke GitHub.

2. Terbitkan token untuk pembeli

Cara kerja singkat

  1. Pembeli bayar QRIS dan mengisi form konfirmasi di website. Anda menerima emailnya beserta bukti bayar.
  2. Cek bukti bayar di mutasi rekening/e-wallet Anda.
  3. Buka halaman ini, pilih paket, isi nama/email pembeli, klik Buat token, lalu kirim pesannya.
  4. Pembeli menempel token di aplikasi: Profil → Premium → Sudah bayar? Masukkan token.
Setiap token punya nomor unik, dan satu token hanya bisa dipakai sekali di satu perangkat. Aplikasi memeriksa tanda tangan tanpa internet.
