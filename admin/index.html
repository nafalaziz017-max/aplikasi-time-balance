Gunakan hanya sebagai admin
Keamanan: panel ini sengaja tidak menyimpan Private Key di server, localStorage, atau URL. Untuk produksi, buka panel ini di komputer admin dan gunakan HTTPS bila dipasang di hosting. Jangan unggah file Private Key ke GitHub.

Catat & verifikasi pembayaran

Website saat ini mengirim konfirmasi melalui email. Setelah kamu mengecek mutasi QRIS, masukkan data pembeli di sini lalu ubah status menjadi terverifikasi. Data panel disimpan lokal di browser admin ini.

Terbitkan token Premium

Token ditandatangani dengan ECDSA P-256. APK hanya menyimpan Public Key untuk memverifikasi tanda tangan. Email token harus sama dengan email akun yang dipakai login di aplikasi.

Manajemen kunci

Jangan membuat pasangan kunci baru sembarangan. Jika Public Key aplikasi diganti, token yang dibuat dengan Private Key lama tidak akan lolos verifikasi pada APK yang memakai Public Key baru. Simpan Private Key di komputer admin dan backup offline.

Jika kamu belum punya Private Key yang cocok dengan Public Key di APK saat ini, buat pasangan baru di sini, simpan Private Key, lalu ganti Public Key di www/app.js dan build APK baru.

Pengaturan panel

Data pembayaran di panel ini bersifat lokal pada browser. Export JSON untuk backup, dan import kembali jika pindah komputer.
