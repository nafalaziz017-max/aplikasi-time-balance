SINKRON DENGAN APK PRODUKSI
Keamanan: Private Key dipakai hanya di browser untuk menandatangani token. Jangan menyimpan Private Key di HTML, GitHub, APK, atau database. Gunakan halaman ini hanya lewat HTTPS dan perangkat admin.

1. Kunci produksi

Public Key di bawah adalah kunci yang sama persis dengan yang tertanam di APK TimeBalance produksi. Jangan diganti.

Jangan klik “buat pasangan kunci baru” di panel ini. Versi produksi sengaja dikunci agar Admin Panel dan APK tetap memakai pasangan yang sama.

2. Terbitkan token

Gunakan hanya setelah pembayaran QRIS diverifikasi.

3. Token untuk pembeli

Token hanya valid untuk email akun yang ditulis di atas.

Token belum dibuat.
APK produksi memakai Public Key yang sama untuk memverifikasi signature ECDSA P-256. Token juga harus memiliki issuer TimeBalance, email akun yang sama, paket yang dipilih, masa Premium, dan batas aktivasi.

4. Alur admin

1. Cek pembayaran QRIS → 2. Verifikasi pembayaran → 3. Masukkan email akun → 4. Pilih paket → 5. Buat token → 6. Kirim token ke pembeli → 7. Pembeli login dengan email yang sama dan memasukkan token di aplikasi.
